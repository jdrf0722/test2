## Introduction [#introduction]

POM (Purcharse Order Menu) Menu allows you to interact with 3 sub-menus: P.O. Processing, Schedule and Departments.

## POM Menu [#menu]

### P.O. Processing Options[#processing]

- Option: **1**  
  P.O. Entry: In this panel/option you can create new Purchase Orders, you can modify them and delete them, you can maintain PO's. A Purchase Order aka PO is attached to a vendor number. Here you can create the, add lines and do/go the pre recieving.

- Option: **2**  
  Buyer Report: This option/program will export a Item Status report to an excel sheet. You can filter using a range of category and Warehouse.

- Option: **3**  
  Buyer Export: Buyer Item export. This panel/option will let you create a buyer item report and export it to an excel sheet. In this panel you can select a biggining and ending category, beggining and ending category and you can filter by buyer too

- Option: **4**  
  Buyer Import: In this panel/option you can import buyer from an excel sheet in your computer

- Option: **5**  
  PO Docs: P/O Attachmnets. In this panel/option you cans select a PO, visualize it's information, retrieve the PO image and add attachments to the PO.

- Option: **6**
  DS Docs: P/O Attachmnets. In this panel/option you cans select a PO, visualize it's information, retrieve the PO image and add attachments to the PO.

### Schedule[#schedule]

- Option: **C1**  
  Schedule: PO recieving schedule view. In this panel/option you will be able to visualize the PO's on the system that are going throuh the receiving process, you will be able to visualize the confirmed, arrived and departed PO's. You can filter by date among others. You can export a report of the PO's to a pdf or a excel sheet.

### Departments[#departments]

- Option: **P**  
  Price Pk / Deals: This option will lead you to Menu PBP (PriceBook/Catalog Master Menu)

- Option: **I**  
  Inventory Dept: This option will lead you to Menu RFF (Inventory Department)

- Option: **S**  
  Sales Dept: This option will lead you to SOP Menu (Sales Menu)

- Option: **M**  
  Shipping Dept: This option will lead you to SHP Menu (Shipping Department)
