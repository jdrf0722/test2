## Introduction [#introduction]

CRM (Customer Credit/Debit Memo System) Menu allows you to interact with 4 sub-menus: Debit/Credit Processing, Manual Credit/Debit Log, CM/DM Reason Codes and Miscellaneous. Use them to create your credits/debits, visualize them and create reports.

## CRM Menu [#menu]

### Debit/Credit Processing[#processing]

- Option: **1**  
  Entry: Old Credit/Debit Entry. This option/program is the old way of creating a Credit/Debit. Consiste of a screen where you can create new Credits or Debits. Currently password potected.

- Option: **2**  
  Printing: One-Step Invoice Printing. Old Credit/Debit Printing. This option/program is the old way to print a Credit/Debit. Consist of a screen where you can print Credits or Debits. Currently password potected. This program have reprint options too.

- Option: **3**  
  Maintenance: Old Debit/Credit log file. In this program/option you can select a Credit/Debit number and see it's information. You can delete and entry and modify it's data. Password Protected.

- Option: **R1**  
  Credit Reporting: CM/DM Monthly Reason Report. In this program/option you can generate a Monthly Reason Report to a pdf. You can export it by reason code, by driver/loader and by route.

- Option: **1N**  
  One Step Entry: In this option/panel you can visualize and modify all the information related to a credit/debit, you can create new ones and you can delete them. In this panel you will need to select the type of credit you will be using, once you do that, you will access the panel that let you modify, create and delete. This is the new better version of option 1.

- Option: **1P**
  One Step Print: P/O Attachmnets. In this panel/option you cans select a PO, visualize it's information, retrieve the PO image and add attachments to the PO.

- Option: **1S**
  One Step Setup: One Step Type Maintenance. Here you can maintain the types of credits, delete them, modify them and create new ones. Example of type of credit/debit: Price Adj Increase. You can use this panel to learn about the type of credits/debits in topshelf and how they work

### Manual Credit/Debit Log[#manual]

- Option: **4**  
  Maintenance: Old Debit/Credit log file. In this program/option you can select a Credit/Debit number and see it's information. You can delete and entry and modify it's data. Password Protected.

- Option: **5**  
  Audit Report: Debit/Credit Log Audit Report. In this option/program you can print a Debit/Credit Log Audit Report. You can select by this options: 1.Only Posted Entries. 2. Only Un-Posted Entries. 3. Posted entries with customer/Amount Mismatches. 4. All Entries. 5. Date Selection(Logged Date).

- Option: **6**  
  Log Clearing Utility: Clear DCL Records Based on Date Entered. In this panel/option youcan clear DCL records based on a date entered. All items prior to the date entered will be cleard as long as the record has been updated with the same customer and amount keyed on the record.

### CM/DM Reason Codes[#reason_codes]

- Option: **C**  
  Reason Code Maintenance: In this program/option you can maintain the reason codes, you can create, delete and modify reason codes data.

### Miscellaneous[#miscellaneous]

- Option: **I0**  
  New Order Locator: Order/Invoice Lookup. In this panel/option you can look up for a customer and see it's credit information. Here you can look up for orders/invoices too

- Option: **I1**  
  Order Locator: This is the order locator. Order Status Inquiry. You can search here information realted to orders. This option/program will let you visualize the information there is for an order, you can search an order here by remote order number, by the customer the order is attached, by it's order number, by phone number, by who was it ordered by and by the customer is being bill to. You could search it by PO number too

- Option: **I2**  
  Open A/R Invoices: Customer Open A/R Invoice Inquiry. In this panel/option you can enter a customer code and the open invoices information for the customer you have entered will be displayed.

- Option: **I3**  
  A/R Invoice History: Customer Open A/R Invoice Inquiry History. In this panel/option you can enter a customer code and the history of invoices information for the customer you have entered will be displayed. All the information about invoices the customer has had, will be displayed

- Option: **I4**  
  One Sysco Reporting: Customer Sales History by Item. In this option/program you will be able to select a sales History Profile and maintain it, you can create, delete, and modify sales history profiles.

- Option: **OA**  
  Credit Reporting: This option will lead you to Menu CRN (Customer Credit/Debit Memo System)
